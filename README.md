# Javier Carrillo Milla

Personal site built with [Next.js](https://nextjs.org/) and TypeScript.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

Static export for GitHub Pages:

```bash
npm run build
```

Output is written to `out/`.

## Pages

- `/` — full-screen background video
- `/about` — bio and main focus
- `/cv` — experience, skills, and education
- `/contact` — services and contact details
